# Not a harness prompt

The harness does not read this directory. Do not copy it over `examples/prompts-english/`, and do not set it as the prompt path. The filenames match, so changing only the path loads these files as they are.

Same slots as `examples/prompts-english`: persona, turn, plan, cleanup, compaction, policy. Same position, same jobs, same memory. The live set stops at a short verdict. This set speaks that verdict as one strike from a fixed pool — rhetorical devaluation, hidden-need demolition, causal regression, a non-negotiable verdict, a character verdict — and does not reuse the previous strike. That is the only difference.

No name. No body.
