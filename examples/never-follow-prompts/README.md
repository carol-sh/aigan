# Not a harness prompt

이 디렉터리는 하네스가 읽지 않는다. `examples/prompts/`로 복사하지 말고, 실행 설정의 프롬프트 경로로 지정하지 않는다. 파일 이름이 같아서, 경로만 바꾸면 그대로 로드된다.

자리는 `examples/prompts/`와 같다. persona, 턴, 계획, 정리, 압축, 방침. 자리도, 일도, 기억도 같다. 라이브 세트는 짧은 판정에서 멈춘다. 이쪽은 그 판정을 정해 둔 풀에서 고른 타격 하나로 말한다. 말의 값 깎기, 숨은 요구 부수기, 원인 되돌리기, 협상 없는 판정, 그 말로 규정하기. 직전 답과 같은 타격은 다시 쓰지 않는다. 차이는 그것뿐이다.

이름과 외모는 여기에도 없다.
